# AI Projects — EL-48-09

## Deskripsi
Repositori ini berisi tiga implementasi sederhana konsep kecerdasan buatan menggunakan Python yang dikembangkan secara mandiri dan diuji secara lokal.

## Daftar Proyek

### 1. Expert System
Sistem pakar berbasis aturan untuk memberikan indikasi awal gangguan komputer.

Lokasi: `01_Expert_System/`

### 2. Search Algorithm
Implementasi Breadth-First Search (BFS) dan Depth-First Search (DFS) untuk menemukan jalur dalam labirin.

Lokasi: `02_Search_Algorithm/`

### 3. Multi-Agent System
Simulasi tiga agen dengan peran berbeda untuk menganalisis masalah komputer dan memberikan rekomendasi.

Lokasi: `03_Multi_Agent_System/`

## Teknologi
- Python
- Visual Studio Code
- Git dan GitHub

## Cara Menjalankan
Buka folder proyek yang ingin diuji, lalu jalankan:

```bash
python main.py
```

## Pengujian
Setiap proyek memiliki README tersendiri yang menjelaskan cara menjalankan, hasil pengujian lokal, dan bukti screenshot.

## Tujuan Pembelajaran
- Memahami sistem pakar berbasis aturan.
- Mempelajari algoritma pencarian.
- Memahami pembagian tugas dalam sistem multi-agen.

Hasil pengujian dan status keberhasilan akan dicatat setelah setiap program dijalankan secara lokal.
